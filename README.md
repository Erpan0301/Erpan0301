## 你好

我是 **Erpan Tudaji**。GitHub 显示名是 **Ervin**，用户名是 [**Erpan0301**](https://github.com/Erpan0301)。

目前公开的项目是 [**PowerTrack**](https://github.com/Erpan0301/PowerTrack)：一套力量训练跟踪与智能分析平台。Flutter 客户端逐组记录训练，FastAPI 提供接口，React 做管理后台。AI 教练走「自己带 Key」——接入任意 OpenAI 兼容接口，密钥留在设备上。

## 精选项目

### [PowerTrack](https://github.com/Erpan0301/PowerTrack)

**力量训练跟踪与智能分析平台**

开源，协议为 [AGPL-3.0](https://github.com/Erpan0301/PowerTrack/blob/main/LICENSE)。逐组记下重量、次数、RPE 和休息，可以对照上次训练；日历里能看到周容量、估算 1RM、力量标准和肌群恢复。动作库支持离线，训练模板和周期可以复用。

| 部分 | 内容 |
| --- | --- |
| `app/` | Flutter 客户端（iOS / Android），含 iOS Live Activity |
| `backend/` | FastAPI、PostgreSQL、Redis、Celery |
| `frontend/` | React、Vite、Tailwind 管理后台 |
| 部署 | GitHub Actions：推送到 `main` 时发布后端 |

[打开 PowerTrack](https://github.com/Erpan0301/PowerTrack) · [提 Issue](https://github.com/Erpan0301/PowerTrack/issues)
